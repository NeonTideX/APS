# Security policy

Security fixes are maintained on `main` and included in the next release. Report vulnerabilities affecting the current V1 release or `main`.

Use [GitHub private vulnerability reporting](https://github.com/NeonTideX/APS/security/advisories/new). Do not post exploitable details, credentials, or private media URLs in public issues.

Include the affected version or commit, browser and userscript manager, reproduction steps, expected impact, and a minimal proof of concept where possible. No response-time guarantee is provided.

APS executes in the page context and stores data in the website's origin storage. It does not provide an isolation boundary against that website's scripts. See the README for storage and compatibility details.
