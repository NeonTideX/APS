# Support

Start with the [README](README.md) and [changelog](CHANGELOG.md). Downloads and release notes are available on the [Releases page](https://github.com/NeonTideX/APS/releases).

## Bugs and feature requests

Use the [issue forms](https://github.com/NeonTideX/APS/issues/new/choose) and search existing reports first. Include browser and userscript manager versions, a reproducible playback example, configuration overrides, and redacted diagnostics.

Security vulnerabilities belong in [private vulnerability reports](https://github.com/NeonTideX/APS/security/advisories/new), as described in [SECURITY.md](SECURITY.md).

## Contributions and expectations

See [CONTRIBUTING.md](CONTRIBUTING.md). Keep reports focused and provide enough information to reproduce the issue. Maintainers provide support on a best-effort basis; there is no response-time or compatibility guarantee.

The maintained release line is 1.x and development continues on main. Older or modified builds may need to be reproduced against the current release before investigation.
